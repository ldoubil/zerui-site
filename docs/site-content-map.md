# 泽锐 zerui 站点内容地图（v1 · 待评审）

> 用途：作为改版与内容生产的协作清单。评审通过后再进入开发，本文档不涉及代码改动与部署。
> 参考站抓取日期：2026-11-25。抓取范围见文末「附录 A」。

## 1. 站点地图

### 1.1 现有结构（已上线）

| 路径 | 现状 | 问题 |
|---|---|---|
| `/` | 全屏 Hero + 产品/工厂/案例预览 + 联系 | 内容均为示例，缺少品牌与信任信息 |
| `/products/` | 4 个品类卡片（示例结构） | 没有品类页、没有型号页、没有规格字段 |
| `/factory/` | 6 步流程 + 3 个占位图块 | 无产能、设备、质检、包装等可验证信息 |
| `/projects/` | 3 张占位卡片 | 没有案例详情，无场景/地区/配置信息 |
| `/contact/` | WhatsApp + 电话 + 渠道列表 | 只有单一通道，缺少合作说明与响应预期 |
| `/robots.txt`、`/sitemap-index.xml` | 已生成，含 hreflang | 保持 |

### 1.3 页面卡

#### `/` 首页（P0，已完成首屏与版块骨架）

- **目标访客**：海外经销商/进口商、设计机构、高端业主；首次进入，判断「是不是真工厂、能不能定制」。
- **版块顺序**：全屏 Hero（定位 + 双 CTA）→ 产品品类 → 工厂与工艺 → 案例精选 → 开始合作 → 页脚。
- **主推关键词**：`outdoor kitchen manufacturer`、`custom outdoor kitchen factory`、`stainless steel outdoor kitchen`；中文：户外厨房制造商、不锈钢户外厨房工厂、定制户外厨房。
- **最终动作**：WhatsApp 询价 / 进入产品总览。

#### `/products/` 产品总览（P0）

- **目标访客**：已知需求、在比对品类与配置深度的采购。
- **版块顺序**：页头说明（OEM/ODM 定位）→ 四个品类入口（各带 1 句适用场景）→ 系列对比（定制 / 标准 / 模块化）→ 定制流程 3 步 → 咨询卡。
- **关键词**：`outdoor kitchen product range`、`modular outdoor kitchen systems`；中文：户外厨房产品、模块化户外厨房。
- **最终动作**：进入品类页；或直接「获取配置清单」。

#### `/products/islands/` 一体化岛台（P0）

- **目标访客**：别墅/庭院项目业主与设计师，关注整体交付与占地。
- **版块顺序**：品类定义 → 适用场景（直排 / L 型 / 岛台）→ 结构与台面选项 → 可集成设备 → 尺寸范围（⚠️待资料）→ 交期/MOQ 摘要 → 咨询卡。
- **关键词**：`outdoor kitchen island`、`custom outdoor kitchen island`；中文：户外厨房岛台、一体化户外厨房。
- **最终动作**：索取尺寸图 / 询价。

#### `/products/modular/` 模块化系统（P0）

- **目标访客**：经销商（看重运输、现场拼装、扩展）、工程项目。
- **版块顺序**：模块说明（柜体/台面/设备/收纳）→ 组合示例（3 种布局）→ 包装与装箱（⚠️）→ 安装条件 → 咨询卡。
- **关键词**：`modular outdoor kitchen`、`modular outdoor kitchen kits`；中文：模块化户外厨房、户外厨房模块。
- **最终动作**：索取模块清单与装箱尺寸。

#### `/products/grills/` 专业烧烤炉（P1）

- **目标访客**：关注烹饪性能的业主与烧烤爱好者、经销商选品。
- **版块顺序**：炉型分类（嵌入/独立）→ 燃烧与材质（⚠️型号参数）→ 与岛台/柜体的搭配 → 认证说明 → 咨询卡。
- **关键词**：`built-in outdoor grill`、`professional outdoor grill manufacturer`；中文：嵌入式烧烤炉、户外烧烤炉厂家。
- **最终动作**：询问型号与配套方案。

#### `/products/cabinets/` 柜体与配件（P2）

- **目标访客**：需要补柜、替换门板或做项目配套的买家。
- **版块顺序**：柜体类型（门板/抽屉/水槽柜）→ 材质与五金 → 尺寸与开孔 → 配件清单 → 咨询卡。
- **关键词**：`stainless steel outdoor kitchen cabinets`；中文：不锈钢户外橱柜、户外厨房柜体。
- **最终动作**：发图纸询价。

#### `/factory/` 工厂与工艺（P0，补内容）

- **目标访客**：正在验厂、比对供应商真实性的 B 端买家。
- **版块顺序**：工厂概览（成立年份/面积/人数/月产能 ⚠️）→ 车间实拍 → 六步工艺流程（现有）→ 质检节点 → 出口包装（⚠️装箱量）→ 认证与合规 → 咨询卡。
- **关键词**：`outdoor kitchen factory China`、`outdoor kitchen manufacturer China`；中文：户外厨房工厂、户外厨房代工厂。
- **最终动作**：预约视频验厂 / WhatsApp 沟通。

#### `/about/` 品牌故事（P0，新增）

- **目标访客**：第一次接触品牌、需要判断「是谁在做」的买家与设计师。
- **版块顺序**：品牌一句话 → 为什么做户外厨房 → 我们坚持的三件事（结构优先/暗处用料/整机交付）→ 团队与工厂（引用 `/factory/`）→ 服务对象（经销商/设计机构/业主）→ 咨询卡。
- **关键词**：`outdoor kitchen brand`、`about outdoor kitchen manufacturer`；中文：泽锐户外厨房、户外厨房品牌故事。
- **最终动作**：继续看工厂页 / 发起咨询。

#### `/custom/` 定制与 OEM（P0，新增）

- **目标访客**：经销商、进口商、需要贴牌或非标尺寸的项目方。
- **版块顺序**：可定制范围（尺寸/布局/材质/颜色/电器/品牌）→ 4 步流程（需求→设计→确认→生产）→ 图纸与确认件（⚠️）→ MOQ 与打样政策（⚠️）→ 常见定制问题 → 咨询卡。
- **关键词**：`OEM outdoor kitchen`、`custom outdoor kitchen manufacturer`、`private label outdoor kitchen`；中文：户外厨房 OEM、户外厨房定制代工。
- **最终动作**：提交需求清单（市场/尺寸/数量）。

#### `/projects/` 案例列表（P0 换内容，P1 做详情）

- **目标访客**：想确认「做过类似项目」的买家。
- **版块顺序**：案例筛选（场景/地区/品类）→ 案例卡片（场景图 + 地区 + 配置摘要）→ 说明（图片授权范围）→ 咨询卡。
- **关键词**：`outdoor kitchen projects`、`outdoor kitchen case study`；中文：户外厨房案例、庭院厨房实景。
- **最终动作**：查看详情 / 询问同类项目。

#### `/projects/{slug}/` 案例详情（P1）

- **目标访客**：深度评估阶段，想看配置与落地细节。
- **版块顺序**：项目概况（地区/场景/交付年份）→ 需求与限制 → 配置清单 → 现场照片（施工/完工）→ 客户反馈（⚠️授权）→ 相关产品 → 咨询卡。
- **关键词**：长尾，如 `outdoor kitchen for villa garden`；中文：别墅庭院户外厨房案例。
- **最终动作**：咨询同类方案。

#### `/shipping/` 交付与物流（P1）

- **目标访客**：进口商、需要核算到岸成本的项目方。
- **版块顺序**：出厂状态（整机/模块）→ 包装方式（木箱/缠膜）→ 装箱量（40HQ ⚠️）→ 贸易条款（FOB/CIF 可谈范围 ⚠️）→ 目的港与安装条件 → 咨询卡。
- **关键词**：`outdoor kitchen shipping`、`outdoor kitchen container loading`；中文：户外厨房海运、整机出口包装。
- **最终动作**：索取装箱图与报价条款。

#### `/warranty/` 售后与质保（P1）

- **目标访客**：担心售后无门的海外买家。
- **版块顺序**：质保范围与年限（⚠️）→ 不覆盖情形 → 备件与响应流程 → 安装/使用注意事项 → 联系售后。
- **关键词**：`outdoor kitchen warranty`；中文：户外厨房质保、售后。
- **最终动作**：联系售后 / 下载说明（⚠️）。

#### `/faq/` 常见问题（P0，新增）

- **目标访客**：所有阶段，尤其临门一脚的犹豫客户。
- **版块顺序**：按主题分组（产品/定制/MOQ 与交期/物流/认证/安装/售后）→ 每组 5–8 问 → 咨询卡。
- **关键词**：`outdoor kitchen FAQ`、`outdoor kitchen MOQ`、`outdoor kitchen lead time`；中文：户外厨房常见问题、起订量、交期。
- **最终动作**：仍有疑问 → WhatsApp。

#### `/guides/` 指南列表（P1）

- **目标访客**：搜索选型/设计/采购知识的早期流量。
- **版块顺序**：栏目说明 → 分类筛选 → 文章卡片（封面/摘要/日期/分类）→ 订阅或咨询入口。
- **关键词**：`outdoor kitchen buying guide`、`outdoor kitchen design ideas`；中文：户外厨房选购指南、设计灵感。
- **最终动作**：阅读文章 → 文末咨询卡。

## 2. 内容缺口对照

> 每条：参考站怎么做（抓取到的实际内容）→ 我们的现状 → 解决什么疑虑 → 我们版怎么写。

### 2.1 品牌故事与工厂实力

- **参考站**：LUXPODIA 有独立 `/about/` 与 `/manufacturing/`，写清 2019 年建厂、2,000 m²、60+ 人、月产能 200+、临沂自有工厂、整机出厂；璞樾 `/about/` 用「五个坚持」讲结构、暗处用料、材质、整机预装、全球气候，并给出 53+ 模块/24+ 配色/3 系列。
- **我们现状**：只有 6 步流程，没有年份、面积、人数、产能、设备。
- **疑虑**：「是不是贸易公司？有没有真工厂？」
- **我们版怎么写**：一段 150 字品牌由来（为什么做不锈钢户外厨房）+ 4 个可核实数字（⚠️待资料）+ 3 条工艺坚持，每条配一张车间实拍；不写「行业领先」这类无法验证的话。

### 2.2 材质与工艺细节

- **参考站**：璞樾把材质拆到参数级——2mm 实心铝板、18mm 304 柜板+铝蜂窝芯、1.5mm 炉体、8mm 烤网、百隆铰链、30,000 次满载伸缩、−40~80℃；LUXPODIA 用「304 stainless steel inside and out」+ 表面处理选项。
- **我们现状**：产品卡片只有一句概述。
- **疑虑**：「用的什么料？两年会不会锈/变形？」
- **我们版怎么写**：做一张「材质与工艺」表（部位 / 材料 / 厚度或规格 / 处理方式），只写已确认项；未确认的留 `⚠️` 不编数字；配 3 张细节特写（焊缝、柜体截面、五金）。

### 2.3 定制 / 配置流程

- **参考站**：璞樾有独立 3D 配置器（开门形式→配置→配色，实时总价、导出配置单）；LUXPODIA 有 4 步流程（Brief→Design→Approve→Produce）并明确「设计支持免费、最终以书面确认为准」。
- **我们现状**：只有 Hero 上一个「获取定制方案」按钮。
- **疑虑**：「定制到什么程度？改图要不要钱？多久确认？」
- **我们版怎么写**：先做 `/custom/` 的 4 步流程 + 可定制范围清单；3D 配置器列为 P2（成本高、需产品数据），先用「配置需求表」（品类/尺寸/电器/数量/目的国）承接。

### 2.4 交付与物流

- **参考站**：LUXPODIA 单开版块讲 40HQ 装 12–24 台、木箱包装、装箱图与毛重随报价确认；璞樾写「整机出厂、水电燃气工厂预装测试、海运木箱、FCL/LCL」。
- **我们现状**：完全没有。
- **疑虑**：「怎么运？运费谁承担？到了能不能卸？」
- **我们版怎么写**：`/shipping/` 写清出厂状态、包装、装箱量（⚠️）、可谈贸易条款、目的港需具备的卸货条件；配 2 张包装/装柜照片。

### 2.5 售后与质保

- **参考站**：LUXPODIA 明确「整机一年质保」，并提示「按订单图纸验收」；璞樾有「安装与验收」环节。
- **我们现状**：没有。
- **疑虑**：「坏了找谁？备件怎么发？」
- **我们版怎么写**：`/warranty/` 写质保年限与范围（⚠️）、不覆盖情形（人为/改装/非正常安装）、备件响应流程（邮件/WhatsApp → 确认 → 发运），不承诺具体小时数除非能履约。

### 2.6 认证与合规

- **参考站**：LUXPODIA 的写法值得直接借鉴——「部分电气件有 CE 文件；整机合规取决于配置与目的国；下单前索取适用文件」，并注明「CE 文件不等于整机合规」；璞樾写烤炉 CE/CSA/AGA 与 CE 电气箱。
- **我们现状**：无。
- **疑虑**：「能不能进欧盟/北美？清关要什么文件？」
- **我们版怎么写**：只列实际持有的证书与对应部件（⚠️扫描件），逐条写「适用范围」；没有的认证明确写「按项目确认」，绝不写「全部通过 CE」。

### 2.7 案例细节

- **参考站**：璞樾 `/gallery/` 是 12 张场景图（地中海庭院、泳池边、夜景等），以场景命名；LUXPODIA 的指南文章明确区分「设计效果图 vs 完工照片」，避免误导。
- **我们现状**：3 张占位卡片，无场景、无地区。
- **疑虑**：「有没有做过我这个气候/这种院子？」
- **我们版怎么写**：案例先按「场景 + 地区 + 配置摘要」三要素建卡；没有授权照片时先用效果图并标注「示意」，有实拍再替换；详情页补需求与限制，比堆美图更有说服力。

### 2.8 常见问题

- **参考站**：LUXPODIA 首页 8 问 + 指南页 10 问，覆盖 MOQ、交期、定制、电器、运输、认证、安装准备、价格构成；璞樾在配置器与联系页反复回答「怎么买」。
- **我们现状**：无。
- **疑虑**：临门一脚的具体问题无人回答。
- **我们版怎么写**：`/faq/` 先做 20 问，按 7 组归类；答案 2–4 句、给条件而不是绝对承诺；每问可锚点分享（`/faq/#moq`），便于 WhatsApp 直接发链接。

## 3. 产品结构

### 3.1 一级品类（沿用现有 4 类，不改业务口径）

| 品类 | 路径 | 说明 |
|---|---|---|
| 一体化户外厨房岛台 | `/products/islands/` | 整机交付，主打项目与高端庭院 |
| 模块化户外厨房系统 | `/products/modular/` | 拆分运输、现场拼装，主打经销与工程 |
| 专业烧烤炉 | `/products/grills/` | 嵌入/独立，可作为岛台配套单独卖 |
| 不锈钢柜体与配件 | `/products/cabinets/` | 补柜、替换、项目配套 |

### 3.2 系列划分方式（建议，⚠️待产品确认）

两个维度，不要混：

1. **按配置深度分系列**（用于营销命名，类似璞樾 CUSTOM / PREMIER / ESSENTIAL）：
   - Custom Line：大尺寸、电动开合、豪华电器、深度定制
   - Premier Line：中小庭院、完整烹饪功能
   - Essential Line：标准化组合、交期短、性价比
2. **按结构形态分型号**（用于 SKU 与图纸）：直排 / L 型 / 岛台 / 模块组合。

> 命名与归属必须先由产品侧确认，文档里只保留结构，不预设具体型号名。

### 3.3 型号详情页字段

| 字段 | 必填 | 来源 | 备注 |
|---|---|---|---|
| 型号名 / 系列 | 是 | 产品 | 营销名与图纸编号分开 |
| 一句话定位 | 是 | 文案 | 30 字内 |
| 整机尺寸（长×宽×高） | 是 | 产品 | 开合状态分别标注 |
| 重量（净重/毛重） | 是 | 产品 | 影响物流报价 |
| 主体材质与厚度 | 是 | 产品 | 只写确认值 |
| 台面选项 | 是 | 产品 | 岩板/石英石/不锈钢 |
| 柜体与五金 | 是 | 产品 | 铰链品牌等 |

### 3.4 列表页筛选维度

## 4. 咨询卡组件

### 4.1 定位

一个共享组件（建议 `src/components/InquiryCard.astro`），替换目前各页零散的 WhatsApp 区块，保证全站转化入口一致、文案可配。

### 4.2 可配置项（props）

| 参数 | 类型 | 说明 |
|---|---|---|
| `eyebrow` | string | 小标签，如 `WHATSAPP` / `OEM` |
| `title` | string（中/英） | 主标题，各页不同 |
| `description` | string（中/英） | 1–2 句，说明「发什么、得到什么」 |
| `primary` | `{ labelZh, labelEn, href, id }` | 主按钮，默认 WhatsApp，走现有 `data-en` + 编码逻辑 |
| `secondary` | `{ labelZh, labelEn, href }` | 可选副按钮（看工厂 / 看案例 / 发邮件） |
| `contacts` | array | 从 `whatsapp / phone / email / wechat` 中选，按顺序渲染 |
| `showPhone` | boolean | 是否显示电话（默认 true；海外页建议 true，国内语境 false） |
| `showEmail` | boolean | 是否显示邮箱（默认 false，邮箱确认后再开） |
| `variant` | `panel` / `inline` / `compact` | `panel` 用于首页与联系页；`inline` 用于文章末尾；`compact` 用于品类页底部 |
| `note` | string | 可选脚注，如「示例内容」「以书面确认为准」 |

> 电话与 WhatsApp 同号时，避免重复展示：`contacts` 里只出现一次，或 `showPhone=false`。

### 4.3 复用页面与文案差异

- 不在组件里写死电话号码：从 `src/data/site.ts` 读取。

### 5.2 文章模板字段

| 字段 | 说明 |
|---|---|
| `title` | 英文主标题（60 字符内）+ 中文标题 |
| `description` | 摘要，120–155 字符，用作 meta description 与列表摘要 |
| `cover` | 16:9 封面，走 Astro 图片处理，带 alt |
| `author` | 作者/团队（先用品牌名，不虚构个人） |
| `date` / `updated` | 发布与更新日期，进 sitemap `lastmod` |
| `category` | 四类之一，对应 `/guides/?category=` |
| `tags` | 3–6 个，用于相关文章 |
| `body` | 固定结构：结论先行 → 分点小标题 → 表格/清单 → 注意事项 |
| `relatedProducts` | 关联 1–2 个品类或型号，正文中与文末各内链一次 |
| `faq` | 可选，文章内 2–4 问，复用 FAQ 样式 |
| `lang` 变体 | 中英同文双版本（`data-en` 或独立路由，见 5.3） |

### 5.3 技术接入

- **RSS**：`@astrojs/rss` 生成 `/rss.xml`，只收指南文章；`<link rel="alternate" type="application/rss+xml">` 加到 Layout。
- **sitemap**：现有 `@astrojs/sitemap` 自动收录；文章 `lastmod` 用 `updated`；为文章补 hreflang（沿用 `?lang=en` 方案）。
- **结构化数据**：文章页输出 `BlogPosting`（headline、description、image、datePublished、dateModified、author、publisher 指向 Organization）；FAQ 区块加 `FAQPage`；面包屑加 `BreadcrumbList`。
- **内链策略**：每篇文章至少 1 条「品类页」+ 1 条「相关文章」；品类页反过来挂 2–3 篇指南；案例详情链到对应品类与指南；锚文本用关键词而非「点击这里」。
- **双语**：文章正文与字段都要中英；若短期只能英文，先只发英文并在中文列表隐藏，避免出现半成品页面。

## 7. 实施顺序建议

### 第一波：现在就能做（不依赖新资料）

1. `/about/`、`/custom/`、`/faq/` 三个新页的**结构 + 文案**（数字位留 `⚠️`）。
2. 咨询卡组件抽离，首页/产品/工厂/案例/联系先接入，统一 WhatsApp 编码。
3. 品类页（4 个）从产品总览拆出，写入「适用场景 + 可定制项」。
4. 案例卡片补「场景 + 地区 + 配置摘要」三要素（先匿名、标注示意）。
5. `/guides/` 列表 + 文章模板 + RSS + sitemap + BlogPosting 结构化数据（先发 3 篇英文）。
6. 页脚补隐私页 `/privacy/`（上表单/统计前必须）。

### 第二波：等资料才能做（P1）

1. 工厂数字条（面积/人数/产能）、车间照片、设备清单 → 工厂页改版。
2. 型号清单与规格表 → 型号详情页批量生成。
3. 认证扫描件与适用范围 → 认证版块（合规写法）。
4. 装箱量、包装照、贸易条款 → `/shipping/`。
5. 质保年限与备件流程 → `/warranty/`。
6. 案例详情 3–6 篇（需授权）。

### 第三波：靠内容量慢慢堆（P2）

1. 指南文章按 B/C 类每周 1 篇，优先 ★ 选题。
2. 案例复盘持续补充（每完成一个项目一篇）。
3. 3D 配置器（需完整 SKU 数据与报价逻辑，成本最高，最后做）。
4. 多语言扩展（除中英外的第三语言）。
