# 图片替换说明（占位图 → 实拍图）

站内所有照片都由 Astro 的 `Image` 组件处理：构建时按页面实际用到的尺寸生成响应式版本，
无需手动压缩或改文件名。替换时**保持原文件名与格式**即可，代码不用动。

## 替换步骤

1. 用同名文件覆盖 `src/assets/images/` 下的占位图（JPG）。
2. 图片颜色模式用 sRGB，单张控制在 2 MB 以内，避免带水印、文字、品牌 Logo（客户授权除外）。
3. 运行 `npm run build` 重新生成；本地用 `npm run dev` 或 `npm run preview` 查看。
4. 打开页面确认裁切：重点内容放在画面中央，四周留出安全边距，避免被 16:9 / 21:9 裁掉。

## 常见问题

- **可以换文件名吗？** 不建议。文件名被 `src/lib/images.ts` 与页面直接引用，改名需要同步改代码。
- **可以换成 PNG/WebP 吗？** 可以，但要同步修改 `src/lib/images.ts` 的导入路径；建议仍用高质量 JPG 作为源文件，由 Astro 输出 WebP。
- **图片会不会被拉伸？** 组件统一用 `object-fit: cover`，只裁切不拉伸；按上表比例拍摄最省事。
- **需要几套尺寸？** 不需要。只提供一张高分辨率原图，构建时自动生成多尺寸。
- **实拍里有人物怎么办？** 需要肖像授权；工厂场景建议拍手部、背影或佩戴防护的侧影，避免正面可识别人脸。
